## Figma File Comparison Tool

This repository also includes a Python tool to compare two Figma design files and generate an Excel report with screen-by-screen comparisons, images, and comments.

### Quick Start

```bash
# Install Python dependencies
pip install -r requirements.txt

# Run comparison (replace YOUR_TOKEN with your Figma API token)
python figma_comparison.py \
  --token YOUR_FIGMA_TOKEN \
  --file1 "FIGMA_FILE_1_URL" \
  --file2 "FIGMA_FILE_2_URL" \
  --output comparison_report.xlsx
```
